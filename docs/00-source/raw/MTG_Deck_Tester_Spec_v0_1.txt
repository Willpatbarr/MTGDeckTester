
MTG Deck Tester
Product Specification v0.1
Status: Draft / Living Document
1. Vision
MTG Deck Tester is a SwiftUI application that allows players to test Magic: The Gathering decks against one or more AI-controlled opponents.
The primary goal is to provide a fast and repeatable environment for solo deck testing and deck development.
Test deck consistency
Test opening hands and mulligans
Test mana curves
Test matchups
Test new card additions
Practice gameplay lines
2. Design Philosophy
2.1 Deck-Centric
Decks are uploaded once and can be used by either humans or bots. A deck has no assigned role. Roles are chosen when creating a game.
Game 1
Player: Yarok ETB
Bot: Goblins

Game 2
Player: Goblins
Bot: Yarok ETB
2.2 Incremental Complexity
The MVP should prioritize playability, speed, and deck testing usefulness over complete MTG rules accuracy.
The application should avoid implementing a full MTG rules engine until later versions require it.

8. Bot System
8.1 Objective
Bots should provide meaningful pressure and interaction for deck testing. Bots are not intended to simulate tournament-level play.
8.2 Turn Flow
Untap
Draw
Play land
Cast spells
Attack
End turn
8.3 Decision Making
Bots use rule-based decision making rather than strategic planning.
If land available
    Play land

If spell affordable
    Cast spell

If attack is favorable
    Attack
9. Simple Bot Mode
9.1 MVP Rule
Simple Bot Mode is always enabled for MVP.
9.2 Purpose
Simple Bot Mode allows bots to use any uploaded deck without requiring a full MTG rules engine.
9.3 Card Simplification
Bots may play any card. However, card behavior is simplified.
Card Type
Simple Bot Behavior
Creature
Becomes a vanilla creature. Uses power, toughness, and mana cost. Ignores abilities, keywords, and ETBs.
Artifact
Played if affordable. Ignored unless future versions add simple artifact rules.
Enchantment
Played if affordable. Ignored for MVP.
Instant
May be cast only during the bot turn in MVP. Simple value effects may be added later.
Sorcery
May be cast during the bot turn. Simple value effects may be added later.
Planeswalker
Played if affordable. Ignored or treated as a threat for MVP.
Battle
Ignored for MVP after being played, or skipped if unsupported.
Land
Played as the bot land for turn.
Examples:
Creature with ETB
→ ETB ignored

Creature with Flying
→ Flying ignored

Creature with Trample
→ Trample ignored
9.4 Future Expansion
Future versions may allow multiple bot rules modes:
Simple
Assisted
Full Rules
MVP uses Simple only.
10. Open Questions
10.1 Gameplay Model
Should the MVP allow players to manually resolve complicated effects, or attempt to automatically resolve some common card effects?
Current recommendation: allow manual resolution for the human player while bots use Simple Bot Mode.
10.2 Format Support
Should the MVP officially support Commander, Modern, Standard, Legacy, and Custom, or simply treat all decks as generic MTG decks?
Current recommendation: generic MTG decks for MVP.
